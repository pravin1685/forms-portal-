🚀 Setup Guide

Forms Portal — Firebase + GitHub Pages · Free Forever

1
Firebase Project बनवा
Free
  1. firebase.google.com वर जा → Google account ने login करा
  2. "Add Project" click करा → Project name द्या (e.g. my-forms-app)
  3. Google Analytics → Disable करा → "Create Project"
  4. Project तयार झाल्यावर → "Continue"
↗ Firebase Console उघडा
2
Web App Register + Config Keys मिळवा
Important
  1. Firebase Console मध्ये → Project Overview → "</> Web" icon click करा
  2. App nickname द्या → "Register app"
  3. खाली दिसणारे firebaseConfig object copy करा:
const firebaseConfig = { apiKey: "AIzaSy...", authDomain: "my-forms-app.firebaseapp.com", projectId: "my-forms-app", storageBucket: "my-forms-app.appspot.com", messagingSenderId: "123456789", appId: "1:123456:web:abc123" };
⚠ हे config index.html आणि admin.html दोन्हींमध्ये PASTE_YOUR_... च्या जागी paste करा.
3
Firestore Database Enable करा
One-time
  1. Firebase Console → Left sidebar → Firestore Database
  2. "Create database" click करा
  3. "Start in test mode" select करा → Next → Enable

नंतर Rules tab मध्ये खाली paste करा (security साठी):

rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { // Anyone can READ (users see forms) match /formsapp/data { allow read: if true; // Only logged-in admins can WRITE allow write: if request.auth != null; } } }
✅ हे rules users ला फक्त read करू देतात. Write फक्त admin login केल्यावरच होतो.
4
Admin User तयार करा (Authentication)
Admin Password
  1. Firebase Console → Left sidebar → Authentication
  2. "Get started" → Email/Password → Enable → Save
  3. "Users" tab → "Add user"
  4. तुमचा admin email + password टाका → Add user
🔒 हा email/password फक्त तुम्हाला माहीत असेल. Users ला कधीही देऊ नका!
5
GitHub Pages वर Publish करा (Free Hosting)
Free Forever
  1. github.com → Sign up (free) → "New repository"
  2. Repository name: forms-portal → Public → Create
  3. तुमच्या 3 files upload करा (index.html, admin.html, SETUP.html)
  4. Settings → Pages → Branch: main → folder: / (root) → Save
  5. 2-3 मिनिटांत live URL मिळेल:
User URL: https://YOUR-USERNAME.github.io/forms-portal/ Admin URL: https://YOUR-USERNAME.github.io/forms-portal/admin.html
↗ GitHub वर जा GitHub Open
6
पहिल्यांदा Forms Add करा
Admin Panel
  1. admin.html उघडा → तुमचा email/password ने login करा
  2. प्रत्येक form ला नाव आणि Google Form URL द्या
  3. "💾 Save All" click करा
  4. User page (index.html) refresh करा — forms दिसतील! ✅
Google Form URL format:
https://docs.google.com/forms/d/FORM_ID/viewform

📁 Files Summary

index.html 👥 User page — forms दिसतात, fill होतात
admin.html 🔒 Admin only — login लागेल, forms manage करता येतात
SETUP.html 📖 हा guide — GitHub वर upload करण्याची गरज नाही

🎉 System Ready!

Admin → forms add करतो → User ला link पाठवतो → User form fill करतो
